# 12 Dienstverlening en support (fase 2)

Wat een klantpraktijk van ProVitaCare mag verwachten. De getallen zijn
voorstellen; stem ze af op wat ProVitaCare werkelijk kan waarmaken. Een
eenmanszaak belooft geen 24/7.

## Beschikbaarheid

| | Voorstel |
|---|---|
| Doel | `[99]` % per maand, tijdens praktijkuren (ma–vr 8.00–17.00) |
| Gepland onderhoud | Buiten praktijkuren, aangekondigd `[2 werkdagen]` vooraf |
| Terugval | Bij een storing schrijft de arts zelf. VitaScribe is nooit de enige manier om een verslag te maken. |
| Status | Een storingsbericht via `[e-mail of statuspagina]` |

## Support

| Prioriteit | Voorbeeld | Reactie | Doel voor oplossing |
|---|---|---|---|
| 1 Kritiek | Niemand kan opnemen; een mogelijk datalek | `[2 uur]` tijdens praktijkuren | `[1 werkdag]` |
| 2 Hoog | Verslagen met structurele fouten; één werkplek werkt niet | `[1 werkdag]` | `[3 werkdagen]` |
| 3 Normaal | Vraag, wens, kleine fout | `[3 werkdagen]` | volgende release |

Kanaal: `[support-adres]`. Stuur nooit patiëntgegevens mee in een
supportvraag. Beschrijf wat er misging, met de versie en het tijdstip.

## Onderhoud

- Updates verlopen via de extensiewinkel, en de server wordt centraal
  bijgewerkt.
- De server meldt de minimumversie van de extensie. Een te oude extensie krijgt
  een waarschuwing.
- Bij een wijziging van een aanbieder, een model of het beoogd gebruik meldt
  ProVitaCare dat vooraf (stuk 04, art. 5, en stuk 11, art. 3).
